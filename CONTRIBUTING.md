# Contributing to GRICS-torch

We welcome contributions to GRICS-torch, including bug reports, improvements to the code, new functionality, tests, and documentation.

## Reporting issues

If you find a bug or encounter a problem, please open an issue on the [GitHub issue tracker](https://github.com/IADI-Nancy/GRICS-torch/issues).

Please provide a description of the problem, the steps required to reproduce it, and the corresponding error messages.

Please do not upload confidential or patient data.

## Suggesting improvements

Suggestions for new features, reconstruction methods, or improvements to existing functionality are welcome.

For substantial changes, we recommend opening a GitHub issue to discuss the proposed implementation before starting development.

## Contributing code

To contribute code:

1. Fork the repository and create a branch for your changes.
2. Follow the existing code structure and conventions.
3. Add or update tests when modifying the reconstruction algorithms or other important functionality.
4. Update the documentation if necessary.
5. Submit a pull request describing your changes.

Contributions will be reviewed by the maintainers before being merged.

## Documentation

Contributions to the documentation, examples, and demonstration notebooks are also welcome. Documentation is available in the `docs/` directory.
